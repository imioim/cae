# RBCAE (Rubric-based Competitiveness Assessment Engine)

평가 틀 파일(JSON)을 읽어 품목 경쟁력 지표를 규칙으로 채점하는 진단 프로그램입니다.
아주대학교 과학기술정책학과 '과학기술과 융합' 기말과제 「산업융합 선도기업 사례연구 - 경쟁력 진단과 강화 방안: ㈜자비스 삼차원 엑스선 단층촬영 자동검사 시스템」의 진단에 사용했습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 채점 엔진. 평가 틀 v0.2가 기본으로 들어 있어 브라우저로 열면 바로 실행됩니다. |
| `engine_template.html` | 평가 틀이 들어가기 전의 엔진 원본. `__RUBRIC__` 자리에 평가 틀 JSON을 넣어 씁니다. |
| `rubric_item_v02.json` | 품목 경쟁력 진단 평가 틀 v0.2 (4개 범주, 자료 항목 14개, 지표 13개) |
| `xavis_evaluation_v02.json` | 평가 틀 v0.2에 ㈜자비스 평가 자료(평가 정보, 입력값과 근거, 기업 여건, 목표 점수)를 함께 담은 파일 |
| `xlsx.full.min.js` | 엑셀 저장용 라이브러리(SheetJS 0.18.5). `index.html`과 같은 폴더에 두어야 합니다. |
| `rubric_schema.md` | 평가 틀 정의 형식 |

## 사용 방법

1. `index.html`을 웹 브라우저로 엽니다.
2. 'JSON 불러오기'를 눌러 `xavis_evaluation_v02.json`처럼 평가 자료가 든 파일을 고릅니다. 평가 대상, 대상 품목, 자료 기준일, 목표 시점, 평가자와 자료 항목 값·근거가 자동으로 채워집니다. 평가 틀만 든 파일(`rubric_item_v02.json`)을 고르면 빈 입력 화면이 열리므로 값을 직접 입력합니다.
3. 내용을 확인하고 '평가 시작'을 누르면 범주별 점수, 과제 후보, 지표별 점수와 판정 근거가 표시됩니다. 평가 뒤에 값을 고치면 결과가 바로 다시 계산됩니다.
4. '평가 저장'을 누르고 저장 형식을 고릅니다.
   - 엑셀(.xlsx): 요약, 지표별 점수, 입력값과 근거, 기업·외부 여건 4개 시트
   - 텍스트(.txt): 같은 내용을 문서 형태로
   - JSON(.json): 나중에 'JSON 불러오기'로 다시 열어 이어서 평가

평가 자료 파일은 평가 틀 JSON에 `evaluation` 항목(`meta`, `values`, `targets`, `overrides`)을 더한 형식입니다.

## 채점 방식

- **구간 대입(range):** 값을 정해진 구간에 위에서부터 대입해 처음 맞는 구간의 점수를 줍니다. 하한은 이상, 상한은 미만입니다.
- **단계 선택(ordinal):** 확인 가능한 사실로 정의한 단계 가운데 해당 단계의 점수를 줍니다.
- **조건 판정(conditions):** 여러 값을 함께 비교합니다. 엔진은 지원하지만 v0.2에서는 쓰지 않았습니다.

값이 없는 지표는 '확인 불가'로 표시하고 점수를 내지 않습니다. 엔진 점수는 초안이며, 평가자가 확정 점수를 바꾸면 수정 사유를 기록합니다.
과제 후보는 중요도 높음, 통제 가능(부분 포함), 최종 점수 2점 이하를 모두 충족하는 지표입니다.

평가 대상이 바뀌면 평가 틀 파일만 새로 작성하고 엔진은 그대로 씁니다.
